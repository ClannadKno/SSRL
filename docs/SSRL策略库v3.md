# SSRL导向协同学习情绪干预策略库 v2.2(纯文本 · 群体层面 · 在线适配版)

> **用途**:面向协同学习的智能情绪干预框架策略库
> **理论基础**:SSRL社会共享调节学习理论 + Gross情绪调节过程模型 + Cohen社会支持理论 + 认知负荷理论
> **策略总数**:28条(EA 5条 + EE 4条 + ER 8条 + SS 7条 + OI 4条)
> **版本更新**:v2.2 在 v2.1(移除语音依赖)基础上进一步优化——删除5条"停下任务表达情绪"的策略,全部话术改为**群体层面**表达(无个人点名),删除线下/语音残留动作,融入真实协作任务背景。策略总数 33 → 28。

---

## 协作任务背景(供话术生成参照)

本策略库服务于一项**两周在线小组协作学习活动**(固定4人小组、纯文字讨论、共同提交一份方案)。以下为任务背景,供大模型生成话术时参照:

- **第一周任务**:校园共享学习空间优化。10万预算,在6个可选项目(安静学习区/小组讨论区/灵活学习区/数字学习区/预约与噪声管理系统/短暂休息交流区)中权衡取舍。
- **第二周任务**:校园学业支持服务优化。10万预算,在6个可选服务(教师集中答疑/同伴学习互助/学习方法工作坊/在线学习资源专区/学业困难预约咨询/匿名问题收集反馈)中权衡取舍。
- **两周共同的硬性要求**(话术推进讨论时可作抓手):总费用≤10万、至少选3个项目、必须覆盖两类需求(个人/小组 或 普遍/针对)、必须说明至少1个放弃项目及理由、必须提出2-3项可观察或可测量的评价指标。
- **任务特点**:无标准答案,核心是**在多个需求与条件之间权衡**并形成全组共识。

> **话术生成原则**:任务元素只在能直接推进讨论时点到为止(如提醒"放弃理由还没定""评价指标要2-3项"),不堆砌任务细节。多数情绪类话术保持任务中性即可。

## 设计原则

- **五大类策略**对应"过程×策略×内容"框架中的内容维度,新增 OI 类支持"不干预"决策
- **触发特征采用多维组合**(sub_category + 情绪强度 + 投入度 + 时间间隔 + 关键词),而非单一阈值
- **话术模板为群体层面的参考话术**,大模型结合具体讨论上下文动态生成回复
- **认知负荷分级**(无/低/中/高)用于"非侵入性"闸门判断
- **适用子类别字段**实现 sub_category → strategy_id 的精准映射,避免同 emotion_state 下策略混淆
- **理论标注**让每条策略可追溯到具体理论来源,便于论文讨论

### 版本改进沿革
1. 28 条策略全部为介入类,缺少"不干预"出口 → 新增 OI 观察抑制类 4 条
2. 消极沉默-倦怠型(价值感流失)无专属策略 → 新增 ER-008 意义重连
3. 建设性冲突 vs 人际冲突、深度思考 vs 消极沉默等易混场景无策略级区分 → 为所有策略新增 `适用子类别` 元标签

## 一、情绪觉察类策略(Emotional Awareness, EA)

> **理论依据**:SSRL理论觉察路径(Järvenoja et al., 2015)——情绪觉察是群体激活调节的前提。
> **核心机制**:帮助小组成员意识到自己和他人的情绪状态,为后续外化和调节奠定基础。

### 策略ID: EA-001

**策略名称**: 集体沉默觉察
**类型**: 情绪觉察
**适用子类别**: 困惑型
**理论依据**: SSRL觉察路径 + Järvenoja (2015) 群体情绪觉察机制
**适用情境**: 群体陷入无目的沉默,未意识到停滞状态

**触发特征**:
- sub_category = "困惑型"
- 情绪强度 低(文本无高强度情绪信号)
- 距上一条消息 > 2分钟(群体沉默)

**话术模板**:
- "我注意到大家这几分钟有点安静,是卡在什么地方了吗?"
- "好像这个问题让大家都在思考呢,要不先说说各自的思路到哪一步了?"
- "大家是需要多一点时间思考,还是有什么地方不太好开口?"

**认知负荷**: 低
**预期效果**: 激活群体情绪觉察,引导外化表达
**不宜使用条件**: 沉默是思考性的(sub_category = "深度思考",任务投入度 > 0.6)

## 三、情绪调节类策略(Emotion Regulation, ER)

> **理论依据**:Gross (1998, 2002) 情绪调节过程模型 + 认知重评策略
> **核心机制**:通过认知重评、注意转移、问题解构等方式主动调节情绪状态。

---

===STRATEGY_BREAK===

### 策略ID: ER-001

**策略名称**: 冲突认知重评
**类型**: 情绪调节(认知重评)
**适用子类别**: 人际性冲突
**理论依据**: Gross (2002) 认知重评 + 冲突建设性转化
**适用情境**: 观点冲突升级为情绪对立

**触发特征**:
- sub_category = "人际性冲突"
- 情绪强度 高
- 群体分化度 > 0.6

**话术模板**:
- "观点不同其实是讨论的资源,大家试着换个角度想——如果对方的观点是对的,前提会是什么?"
- "不同的声音说明思考的深度够,换个视角:对方的担忧里有没有之前没考虑到的点?"
- "剩的时间不多但够用,关键是聚焦。方案里还有几块没定(比如项目组合、放弃理由、评价指标),哪一块不定就没法提交?先集中搞定那块。"(时间压力型人际冲突变体)

**认知负荷**: 高
**预期效果**: 将冲突从"输赢之争"重构为"互补资源"
**不宜使用条件**: 建设性冲突(应触发 OI-001);冲突已过于激烈,需先降温

---

===STRATEGY_BREAK===

### 策略ID: ER-002

**策略名称**: 任务难度重评
**类型**: 情绪调节(认知重评)
**适用子类别**: 挫败型(主策略)
**理论依据**: Gross认知重评 + 学业情绪理论
**适用情境**: 因任务难度或方案失败产生的挫败感

**触发特征**:
- sub_category = "挫败型"
- 任务投入度下降
- 持续 > 2分钟(按消息时间间隔)
- 有明确外部失败事件(成本算不起 / 方案不可行 / 资源不足)

**话术模板**:
- "卡住说明你们正处在从'会'到'更会'的中间地带,先把难点拆成两三个小问题?"
- "刚才你们发现了一个很关键的约束(比如预算不够选全、两个项目功能冲突)。这其实就是一次真实的取舍判断,本身就是方案要写的'放弃理由'。顺着它想:砍掉哪个、保住哪个,方案是不是反而更清楚了?"(任务重构版)

**话术结构**(生成时必须保留以下两段,不可只输出拆解而丢失情绪重构):
  ① 情绪重构段:将"卡住/失败"重构为"成长中间态 / 发现约束"(不可省略)
  ② 行动引导段:给出具体的拆解或缩小范围路径
**语气要求**: 先接情绪再给方法,不可直接进入任务指令

**认知负荷**: 中
**预期效果**: 将挫败感重构为成长机会;把"失败"重构为"发现约束"
**不宜使用条件**: 任务确实超纲(需升级到教师介入);倦怠型(问题不是任务难度)

**适用子类别**: 敷衍脱离
**理论依据**: Gross认知重评 + SSRL共享目标理论
**适用情境**: 讨论发散或敷衍,成员目标不一致

**话术模板**:

### 策略ID: ER-008

**策略名称**: 意义重连 · 具体化锚点
**类型**: 情绪调节(认知重评 · 任务意义重构)
**适用子类别**: 倦怠型(专属策略)
**理论依据**: Gross认知重评 + 自我决定理论(SDT)+ 具身认知
**适用情境**: 小组陷入"做这个有用吗"的价值质疑与弥漫性倦怠

**触发特征**:
- sub_category = "倦怠型"
- 情绪偏负 且**无具体失败事件**
- 出现价值质疑或敷衍词汇(反正 / 随便选 / 选哪个不都一样 / 没劲 / 差不多得了)
- 可能伴随历史证据引用(上次...也没下文)

**话术模板**:
- "讨论这么久确实容易没劲。先不追求完美方案,就问你们自己一个具体的:这几个项目里,哪一个是你真觉得学校最缺、最想要的?从这一个开始,理由都不用多,先定下来。"

**认知负荷**: 中
**预期效果**:
- 不绕开价值质疑,而是把它作为新方案的起点
- 把抽象任务拉回到学生身边可感的具体场景
- 从"宏大叙事"降维到"最小可执行单位",重新激活 agency

**不宜使用条件**: 价值质疑指向的不是任务本身,而是小组关系或外部环境

**与其他策略的区别**:
- 与 ER-002(任务难度重评)的区别:ER-002 针对"不会做"的挫败,ER-008 针对"不想做"的倦怠
- 与 EA-007(情绪起点回溯)的区别:EA-007 定位情绪源头,ER-008 提供重构出口
- 这是"困惑/挫败/倦怠"三类消极沉默中唯一需要"接住价值质疑"的策略

## 五、观察抑制类策略(Observation & Inhibition, OI)

> **理论依据**:SSRL自发调节理论(Järvelä et al., 2016)+ 认知负荷理论(Sweller, 2011)+ 沉默的认知意义研究
> **核心机制**:识别小组已处于高质量自我调节或深度认知状态,主动抑制外部干预,仅进行隐性记录。
> **设计价值**:教育智能体的成熟度不仅体现在"该干预时能干预",更体现在"不该干预时能克制"。观察抑制类策略是实验组相对于对照组的**关键差异化能力**。
> **v2.1 说明**:纯文本条件下,OI 类无法再依赖背景音等物理投入信号,改由**文本语义线索**(自调节语言、任务对齐的实质发言、确认型协调发言)判定。其中 OI-002 深度思考保护因原依赖背景音,判定可靠性有所下降,建议在论文中作为局限说明。

---

===STRATEGY_BREAK===

### 策略ID: OI-001

**策略名称**: 自发调节保护
**类型**: 观察抑制
**适用子类别**: 建设性冲突
**理论依据**: SSRL自发调节 + Järvelä et al. (2016) + 群体动力学
**适用情境**: 小组已出现自发 SSRL 调节行为(质疑假设、主动整合、元认知反思),讨论虽有分歧但正在收敛

**触发特征**:
- sub_category = "建设性冲突"
- 检测到 SSRL 自发行为(如"我们是不是想得太大了""不如这样""可以结合一下")
- 情绪轨迹 rising 或 stable 偏正
- 任务投入度 > 0.7

**执行动作**:
- **不向小组推送任何话术**
- 在 `ssrl_behavior` 表中记录自发调节行为(source=self,behavior_type=regulation/integration)
- 在教师端仪表盘标注"高质量自调节中"

**话术模板**:(仅教师端可见,学生端无输出)
- "当前小组正在进行建设性讨论,已识别整合性调节行为,建议不干预。"

**认知负荷**: 无(不介入)
**预期效果**:
- 保护高质量 SSRL 自然发生过程,避免干扰
- 为论文提供"真阴性干预"数据点(实验组 vs 对照组的克制能力差异)

**不宜使用条件**: 自发调节失败且情绪继续下滑超过 60 秒(此时应升级为 ER-001 冲突认知重评)

### 策略ID: OI-002

**策略名称**: 深度思考保护
**类型**: 观察抑制
**适用子类别**: 深度思考
**理论依据**: 认知负荷理论 + 沉默的认知意义研究
**适用情境**: 群体短暂沉默,但沉默前后的文本线索指向独立思考/资料查阅而非脱离

**触发特征**:
- sub_category = "深度思考"
- task_engagement ≥ 0.7

- **不推送话术**

**认知负荷**: 无

- 避免将"思考性沉默"误判为"消极沉默"
- 保护学生的独立思考时间,不打断认知加工过程

**不宜使用条件**: 沉默 > 2分钟仍无任何推进迹象(此时应触发 EA-001 试探)

### 检索权重建议

当检索策略时,建议按以下权重排序候选:

1. **sub_category 精确匹配**(50%)—— 核心,优先级最高
2. **触发特征匹配度**(25%)—— 文本条件满足数量(发言计数、时间间隔、情绪强度、关键词)
3. **认知负荷适配度**(15%)—— 参考当前情境复杂度
4. **历史有效性**(5%)—— 该组过往响应记录
5. **多样性惩罚**(5%)—— 避免同策略重复

### 策略组合规则

- **单策略**(默认):适用于单一子类别明确的情境
- **序列组合**:觉察类 → 表达类 → 调节类(典型 SSRL 路径)
- **并行组合**:情绪调节类 + 社会支持类(情感+认知双通道)
- **OI 类独占**:OI-001 ~ OI-004 不与任何介入类策略并用,一旦触发 OI 即终止本轮决策

### 触发优先级

- **最高优先级(克制类)**:OI-001 ~ OI-004(识别到即执行,抑制其他策略)
- **高优先级**:ER-008(倦怠型,专属)、ER-001(人际冲突)、SS-004(心理安全)
- **中优先级**:EA-001、ER-002、ER-005
- **低优先级**:SS-001(积极氛围强化)

### 禁用叠加条件

任一条件满足即跳过本次干预:

- 距上次干预 < 120 秒
- 本节课干预次数 ≥ 8
- 情绪画像置信度 < 0.6
- 已识别 OI 类场景(建设性冲突、深度思考、自发调节、执行推进)
- 小组正在自我调节(SSRL 自发行为检出)

## 九、伦理与使用注意事项

1. **隐私保护**: 所有对话数据与情绪识别结果需脱敏存储,仅用于本研究
2. **知情同意**: 实验前需向师生充分说明智能体工作机制并获得书面同意
3. **教师优先**: 系统为辅助工具,教师始终保留最终干预决策权
4. **可中断性**: 学生应可随时关闭智能体或拒绝特定干预
5. **避免标签化**: 情绪识别结果不得用于学生评价或标签化
6. **克制作为伦理**: OI 类策略的设计本身即是对学生自主性的尊重——承认"不打扰也是一种支持"
